
# Medical FactGuard AI

AI-powered Medical Misinformation Detection and Evidence-based Verification.

## 1. Project Overview

Medical FactGuard AI is an AI-powered system designed to detect and evaluate potentially misleading medical information using scientific evidence.

The system analyzes medical claims, retrieves relevant research, evaluates evidence, and generates explanations with reliable references.

## 2. Target Categories

1. Vaccines & Immunization
2. Medications & Treatments
3. Cancer-related Medical Information

## 3. Core Algorithms

- Medical Claim Extraction
- Medical Topic Classification
- Local Search Optimization
- Semantic Similarity
- Evidence Analysis
- Bayesian Inference
- Probability Estimation
- Uncertainty Estimation

## 4. Technology Stack

- Python
- FastAPI
- JavaScript
- Chrome Extension (Manifest V3)
- Scikit-learn
- PubMed API

## 5. Project Structure

- extension/: Chrome Extension
- backend/: AI analysis backend
- demo/: Demonstration website
- data/: Test datasets
- tests/: Algorithm tests
